# 英语 · 科目说明

> 「小小刷题家」科目仓库统一说明文档 · 生成于 2026-11-17 版本迁移

## 科目标识

- **科目名称**：英语
- **目标教材**：外研版（三起）六年级上册（2026 新版 6 单元）
- **题库规模**：单元测验 47 题（Unit 1）+ 全册渲染器；正式库另有仿真套卷 90 套/6137 题（在 NAS）
- **所属应用**：小小刷题家（fnOS NAS 内网部署，http://192.168.31.88:18900）

## 目录结构（统一规范）

```
英语单元卷/
  build_unit1.py            Unit 1 测验生成器（47 题/100 分）
  to_bank.py                题目转题库条目（题型映射 + Unit1 前缀）
  六上全册/render.py         全册试卷渲染
```

## 数据来源与口径

- A4 版式：试卷 4 页 + 答案 2 页；听力音频 edge-tts en-GB
- 教材结构：U1 What do you do with money? … U6 See the world
- 坑位：<u> 父容器禁 flex；assign_scores 全局均分需自控

## 与主项目的关系

- 题库运行时数据（SQLite）在 NAS `data/shuatixia-kids.db`，**不入库**（含孩子答题记录）
- 本仓库只存内容与工具，可随时据 `scripts/` 重建题库
- 基线快照见 [shuatixia-baseline](https://github.com/weifang11233/shuatixia-baseline)（私有）
